Tutorials: JavaScript Basics

Welcome to Macro Wars! You will write your bot logic in JavaScript.

1. The Return Statement

Your script must return an action object every turn:
return { command: "move", x: 5, y: 5 };

2. Accessing Game State

Use gameState.myShips[0] to find your ship. Use gameState.myMacros to check your bank.

3. If Statements

Make decisions:
if (gameState.myMacros > 5) { return { command: "attack" }; }
